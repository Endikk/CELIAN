# CELIAN

Générateur de projets d'architecture dev et data. Après un entretien guidé, il
produit un dépôt complet (infrastructure as code, Kubernetes, CI/CD, sécurité,
conventions Git, documentation). Ce dépôt démarre en une commande sur un PC et
se déploie sur la cible choisie.

État : phase 0, cadrage. Rien n'est encore utilisable.
